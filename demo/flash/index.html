Install the web interface on your ESP32

Install from your browser

Plug the board into this computer with a USB data cable, pick a release and press Install. The right image for your chip (classic ESP32 or ESP32-S3) is chosen automatically.

Release
Your browser can't talk to USB devices. Use Chrome or Edge on a computer (Windows, macOS, Linux or ChromeOS). This page has to be opened over https to reach USB devices. Tested releases.

No release images are bundled with this copy of the page. Download one from GitHub Releases instead.

First install

  1. Connect the board by USB and press Install, then choose its port.
  2. Tick Erase device for a clean start (recommended on a new board).
  3. When it's done, join the board's Wi-Fi access point and open http://192.168.4.1/.
  4. Under Settings → Device & Connection, pick your board's UART or CAN pins.

Already installed?

Update over Wi-Fi from the board's own Update page instead: it keeps your settings, users and Wi-Fi, and puts your gauge layouts back after the reboot.

Installing here with Erase device wipes everything on the board, including Wi-Fi and user accounts.

If it doesn't connect

  • No port in the list: use a data cable (not charge-only) and install the USB driver for your board (CP210x or CH340).
  • Stuck at “Connecting”: hold the BOOT button, press and release RESET (EN), then release BOOT.
  • Port busy: close any serial monitor (Arduino IDE, PlatformIO) that has the port open.
  • Prefer a command line? esptool.py write_flash 0x0 esp32_vX.Y-0x000.bin with an image from Releases.
