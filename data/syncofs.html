Syncofs tuner

← Back to the web interface

For permanent-magnet motors on the FOC firmware. Start the inverter (Run), raise manualid a few amps at a time, then turn syncofs: at the right offset the motor stays still. The graph keeps the speed seen at each offset; keep the syncofs of the dip and save the parameters. Turn manualid back to 0 when done.

This inverter has no syncofs / manualid parameter. The tuner needs the stm32-sine FOC firmware.
The inverter is not in Run: manualid only takes effect while it runs. Start it from the main interface first.
